# EZwww

### 🛠️ 사용 기술
HTML CSS JAVASCRIPT <br />
PHOTOSHOP FIGMA 

### 📚 학습 목표
1. HTML, CSS, JavaScript의 기본 개념 및 문법 이해<br/>
2. HTML과 CSS 와 JAVASCRIPT를 이용하여 여러가지 페이지 디자인 <br />
3. JAVASCRIPT를 이용하여 가위바위보,  기능 만들어 보기<br />
4. JQUERY를 이용하여 JAVASCRIPT로 만든 기능들과 비교하여 기능만들어보기<br />
5. PHOTOSHOP과 FIGMA을 이용하여 이미지를 계획하고 디자인 <br />

### 프로젝트 목표
HTML과 CSS 와 JAVASCRIPT를 이용하여 여러가지 페이지의  프로트엔트 작업을 익힌다.<br />
또한 PHOTOSHOP과 FIGMA을 이용하여 이미지를 계획하고 디자인한다.
